# 《INFP 的成长路线》分镜

依据：`prompt/brief.md`、`research/sources.md`。表述编号（S1、B1 等）对应 sources。

## 约定

- **时间**：默认按 120 秒视觉节拍排布，**未卡点**。所有动画按「段内进度 p（0–1）」计算，载入 Suno 音频后用校准模式重写锚点，画面随之伸缩。
- **画幅**：每段分别写 9:16（主）与 16:9 构图。9:16 顶部 12%、底部 20% 为平台 UI 避让区；字幕位于画面 62%–76% 高度。
- **母题**：内在光点（Fi）贯穿全片，状态变化即成长弧线：被包裹 → 分叉 → 困在回路 → 被打开 → 连接路径。
- **色彩**：雾面纸白底 `#EEEBE4`，墨蓝 `#1F2E45` 主色；苔绿 `#6F8A5B` 只从段落 06 起出现，代表「行动 / 落地」。
- **字体**：主文案为衬线宋体；Fi、Ne、Si、Te 用等宽字体作为标签。
- **措辞**：理论用「在类型学中」「这个框架认为」；社区说法用「社区里常说」；不出现「科学证明」。

## 段落 00 · 钩子：三个瞬间（0–12s）

- **目的**：用三个具体行为让观众认出自己，制造「为什么会这样」的问题。
- **起始状态**：纸白底，中央一个很小的墨蓝光点，安静呼吸。
- **触发**：播放开始。
- **变化链**：
  1. p 0–0.3：光点上方出现一张清单，条目一行行写满，第一行的勾选框始终是空的。字幕「计划写满了，第一步还没开始。」
  2. p 0.3–0.6：清单收起，一句话的文字框出现，同一句被删改、重写三次。字幕「一句话发出去前，改了很多遍：这样说，会不会不对？」
  3. p 0.6–0.85：画面突然收紧，四周出现锐利的红笔批注划向光点。字幕「累的时候，你对自己特别狠。」
  4. p 0.85–1：批注定住，标题浮现「这些，可能是同一套机制」。
- **重音**：第 3 拍画面收紧（约 8s），全段唯一的锐利形态。
- **结果状态**：光点被批注包围，标题停留。
- **9:16**：清单、文字框、批注均竖向排列在画面上中部，光点位于 40% 高度。
- **16:9**：三个情境从左向右依次出现，前一个变淡但保留，光点居中。
- **依据**：S3、S4、S5；第 2 拍已按反巴纳姆检查改写，绑定到「是否违背自己的价值」。
- **下段联系**：批注退去，镜头推入光点内部。

## 段落 01 · 框架：四个功能（12–26s）

- **目的**：给出类型学的描述框架，并立刻声明它是理论模型。
- **起始状态**：光点放大为中心圆。
- **触发**：上一段镜头推入。
- **变化链**：
  1. p 0–0.25：小字标签出现「在荣格类型学中」。
  2. p 0.25–0.7：四个圆依次出现并排成层级，尺度与亮度递减：Fi（最大、最亮）、Ne、Si、Te（最小、最淡）。每个圆出现时带一个两字短释：Fi「价值」、Ne「可能」、Si「记忆」、Te「执行」。
  3. p 0.7–0.9：Te 圆轻微闪烁、偏离队列。字幕「最后一个，是最不熟练的那个。」
  4. p 0.9–1：角落出现常驻小字「理论模型，不是测量结果」，随后缩小到角标，持续到段落 05。
- **重音**：Te 偏离（约 23s），为后面「压力下的 Te」埋参照。
- **结果状态**：四个功能的层级图。
- **9:16**：四个圆竖向排列，自上而下变小。
- **16:9**：四个圆横向排列，自左向右变小。
- **依据**：F1、F3、F4；F4 出处待核实，片中不写提出者。
- **下段联系**：Ne、Si、Te 退为浅色背景，保留 Fi 与 Ne 进入下一段。

## 段落 02 · 特质：Fi 与 Ne（26–38s）

- **目的**：用状态变化解释前两个功能，而不是贴形容词。
- **起始状态**：Fi 圆在中心，Ne 在旁。
- **触发**：Ne 向 Fi 靠拢并融入。
- **变化链**：
  1. p 0–0.4：Fi 圆内出现一根指针，像罗盘。外面飘来几件事，指针对每件事左右摆动后定住：一件被吸收，一件被推开。字幕「Fi：先问，这符不符合我心里的标准。」
  2. p 0.4–0.85：从 Fi 向外长出许多分叉线，每根末端是一个小圆点（一种可能），分叉越来越多。字幕「Ne：再看见很多种可能。」
  3. p 0.85–1：分叉线停住，末端圆点全部悬空，没有一个落地。
- **重音**：分叉线爆发式增长（约 33s）。
- **结果状态**：罗盘光点 + 一整片悬空的可能性。
- **9:16**：分叉向上方和两侧生长，下方留出空白「地面」。
- **16:9**：分叉向右侧生长，右侧边缘为「地面」。
- **依据**：S1、S2。
- **下段联系**：悬空的末端圆点直接成为段落 03 的起始画面。

## 段落 03 · 原生①：可能性太多（38–50s）

- **目的**：解释「计划写满却不开始」在框架里的来源：Ne 发散很强，Te 执行很弱。
- **起始状态**：上一段悬空的可能性圆点。
- **触发**：一个圆点尝试向「地面」下落。
- **变化链**：
  1. p 0–0.3：一个圆点向地面下落，接近时又分裂成三个新圆点，弹回空中。字幕「每次想开始，又冒出更好的方案。」
  2. p 0.3–0.6：重复两次，圆点越来越多，画面变密，地面仍是空的。
  3. p 0.6–0.85：段落 01 的 Te 小圆在地面边缘淡淡出现，几乎看不清。字幕「这个框架认为：想法来自 Ne，落地要靠最不熟练的 Te。」
  4. p 0.85–1：密集的圆点整体停顿。
- **重音**：圆点密度达到全片最高（约 47s）。
- **结果状态**：画面上半部挤满可能性，下半部空白。
- **9:16**：上下对比最强，上 60% 密集、下方空白，利用竖屏高度表现「落不下来」。
- **16:9**：左侧密集、右侧空白，地面改为右侧边缘。
- **依据**：S3（理论推论，用「这个框架认为」）。
- **下段联系**：圆点向中心收拢，连成一个圆圈。

## 段落 04 · 原生②：回路（50–62s）

- **目的**：呈现「在心里反复评判」的封闭状态，并标明这是社区说法。
- **起始状态**：圆点收拢成一个围绕 Fi 的圆圈。
- **触发**：一个小亮点开始沿圆圈绕行。
- **变化链**：
  1. p 0–0.3：亮点在 Fi 与圆圈上的 Si 节点之间来回绕行，每绕一圈留下一道淡痕。字幕「一句话，在心里来回审了很多遍：它是不是背叛了我在意的东西？」
  2. p 0.3–0.6：绕行加速，淡痕叠加成越来越粗的环，圆圈外侧原本的分叉线（Ne）逐渐褪色、消失。
  3. p 0.6–0.85：小字标签出现「社区里常说：Fi-Si 回路」，下方附注「跳过了向外的 Ne」。
  4. p 0.85–1：环变得很厚，Fi 光点在环内变暗。
- **重音**：Ne 分叉线完全消失（约 58s），封闭感成立。
- **结果状态**：厚重的圆环包住变暗的光点。
- **9:16**：圆环位于 38% 高度，直径约画面宽度 70%。
- **16:9**：圆环居中偏左，右侧留出段落 06 打开方向的空间。
- **依据**：S4（社区说法，必须带「社区里常说」标签）。
- **下段联系**：圆环保留，压力从外部挤入。

## 段落 05 · 原生③：压力下的 Te（62–72s）

- **目的**：解释「累的时候对自己特别狠」：劣势功能在压力下以不成熟方式出现。
- **起始状态**：厚环包住暗光点。
- **触发**：画面边缘向内收紧（呼应段落 00 第 3 拍）。
- **变化链**：
  1. p 0–0.3：四周压缩，背景从纸白变为偏灰。段落 01 偏离队列的 Te 小圆突然放大，冲到画面前方。
  2. p 0.3–0.6：Te 变成尖锐的多边形，射出红笔式的直线批注：打叉、划线、「不够好」。字幕「压力大时，平时最弱的 Te 会突然接管：挑剔、苛刻、急着纠错。」
  3. p 0.6–0.85：批注不是射向外界，而是全部射回中心的光点。
  4. p 0.85–1：音乐 Break 处整体定格，只留一个持续的停顿。小字「类型学认为：这是劣势功能被压力放大」。
- **重音**：Te 多边形冲到前方（约 64s），全片最锐利、最压迫的一帧。
- **结果状态**：光点被批注和厚环双重包围，画面最暗。
- **9:16**：Te 多边形从下方冲入，占画面中部，批注向上射向光点。
- **16:9**：Te 从右侧冲入，批注向左射向光点。
- **依据**：S5、F5；Quenk 原文措辞核实前，不直接写「Quenk 说」，只用「类型学认为」。
- **边界**：不使用任何临床词汇，不暗示这是心理问题。
- **下段联系**：定格之后，第一道苔绿色出现，进入段落 06。

## 段落 06 · 中阶：打开回路（72–90s）

- **目的**：给出第一步方向：重新用 Ne 向外连接，做小而可完成的事，表达边界。标明这是常见说法与一般建议。
- **起始状态**：定格的暗画面，厚环与批注包围光点。
- **触发**：厚环上出现一道细小的缺口，缺口处透出第一抹苔绿（全片首次出现）。
- **变化链**：
  1. p 0–0.25：批注一条条失去颜色、落下。字幕「社区里常说：走出回路，靠的不是更用力地想，而是向外走一步。」
  2. p 0.25–0.5：一根 Ne 分叉线从缺口伸出，这次只有一根，不再分裂。它延伸到「地面」，末端圆点第一次落地，变成苔绿色。字幕「先做一件小到能完成的事。」
  3. p 0.5–0.75：落地点旁出现一道短短的苔绿竖线，像一堵矮墙，外来的灰色批注碰到它后停下。字幕「把「不」说出口，也是在保护你在意的东西。」
  4. p 0.75–1：厚环逐渐变薄、断开成弧线，Fi 光点重新变亮。背景从灰回到纸白。
- **重音**：第一个圆点落地并变绿（约 78s），与段落 03「落不下来」形成直接对照；音乐 Chorus 起点落在此处（待校准）。
- **结果状态**：光点变亮，一根绿线连到地面，一个落地点，一道边界线。
- **9:16**：缺口在圆环下方，绿线竖直向下伸到地面，复用段落 03 的上下结构。
- **16:9**：缺口在圆环右侧，绿线向右伸到边缘地面，复用段落 03 的左右结构。
- **依据**：S6（社区说法 + 一般建议，不说成理论结论）。
- **下段联系**：落地点成为一条路径的起点。

## 段落 07 · 高阶：价值落成行动（90–106s）

- **目的**：呈现成长的更远方向：Te 被整合，价值不再只用来评判自己，而是指引方向、落成结构与产出。
- **起始状态**：一个落地点，光点悬在上方，Te 小圆在地面一侧。
- **触发**：Fi 罗盘指针重新出现，指向一个方向，而不是左右摆动。
- **变化链**：
  1. p 0–0.3：沿指针方向，从落地点向前铺出一条路径，路径上依次出现苔绿色的完成节点。字幕「这个框架认为，成长包括把弱的功能慢慢接上。」
  2. p 0.3–0.6：Te 小圆从多边形（段落 05 的形态）变回圆形，移到路径上，成为路径的「步伐」：每走一步，留下一个节点。字幕「Te 不再是压力下的批评者，而是把想法变成步骤的那只手。」
  3. p 0.6–0.85：几根 Ne 分叉线重新出现，但这次每根都连到路径上的某个节点，可能性有了落点。
  4. p 0.85–1：Fi 光点、路径、节点连成一个整体。字幕「价值，从用来评判自己，变成用来指路。」
- **重音**：Te 从尖锐多边形变回圆形（约 96s），段落 05 的直接反转。
- **结果状态**：一条带有多个完成节点的路径，由光点指引。
- **9:16**：路径由下向上蜿蜒生长，穿过画面中部；竖屏高度用于表现「走了很远」。
- **16:9**：路径由左向右延伸，横跨画面。
- **依据**：S7；「高阶」分级为社区说法，片中不出现「高阶」一词作为结论，只在段落标题使用。
- **下段联系**：路径保留，四个功能标签淡出。

## 段落 08 · 边界与收尾（106–120s）

- **目的**：说明这是一套自我觉察的语言，不是诊断，也不是科学定论；落在「看行为，不贴标签」。
- **起始状态**：完整路径与光点。
- **触发**：画面缓慢拉远。
- **变化链**：
  1. p 0–0.3：「I N F P」四个字母在画面上方出现，随后逐个淡去。字幕「类型是一种语言，不是一个判决。」
  2. p 0.3–0.6：边界说明以小字整段停留，阅读时间充足：「功能顺序与回路是理论描述，不是测量结果；MBTI 的重测稳定性一直存在争议。」
  3. p 0.6–0.85：字幕「比起记住四个字母，更值得看见的，是你已经走出的那一步。」
  4. p 0.85–1：只剩光点与路径，路径末端的最后一个节点轻微亮起，淡出。
- **重音**：字母淡去、路径留下（约 110s）：标签消失，行动留下。
- **结果状态**：纸白底上的一条苔绿路径与墨蓝光点。
- **9:16**：字母位于上方 20% 高度，边界说明位于字幕区，保证在平台 UI 之上可读。
- **16:9**：字母居中上方，说明文字在下三分之一。
- **依据**：B1、B3；B1 不写任何具体比例数字。
- **下段联系**：片尾。
