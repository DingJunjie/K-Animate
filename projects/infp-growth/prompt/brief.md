# 《INFP 的成长路线》任务书

- **模式**：`knowledge`
- **载体**：`web`（浏览器自动播放的字幕短片），导出后发布到抖音等平台
- **时长**：120–180 秒，以内容讲清为准；最终以 Suno 音频为准，待校准
- **画幅**：9:16（主，1080×1920）、16:9（1920×1080）
- **系列**：MBTI 成长系列第 1 部，计划共 16 部
- **声音**：Suno 生成的纯音乐，无人声、无旁白

## 声音与文字

- 无旁白，字幕承担全部信息（Suno 不生成旁白，本轮不引入 TTS）。字幕需要独立讲清内容。
- 变化难以纯靠画面描述时，允许用粒子、光与语言营造感觉；以「感觉成立、信息讲清」为准，不要求每个概念都有具象画面。

## 系列约定

本片是 16 型系列的第 1 部。系列共享的部分将来提取为系列层文件，本片先在项目内实现。

- 共享：内容结构（钩子 → 框架 → 特质 → 发展 → 原生状态 → 成长 → 边界）、功能圆的视觉语法、知识边界写法、片尾说明。
- 每型独立：功能顺序、具体行为、母题形态、强调色与音乐。
- 同一结构不等于同一画面：每型的母题应来自其功能组合（如 INFP 的罗盘与回路），避免 16 部变成换字幕的模板。

## 观看结果

观众看完后：
1. 知道 INFP 在类型学中的描述框架（认知功能顺序），而不只是"敏感、善良"等标签。
2. 能认出几个具体的"原生状态"行为模式，并理解它们在这个框架里的解释。
3. 看到一条可执行的成长方向：从"在心里评判"到"把价值落成行动"。
4. 明白这是一套自我觉察的语言，不是诊断，也不是科学定论。

## 观众

- 自测是 INFP 或对 MBTI 感兴趣的年轻用户，已知道四个字母，可能不了解认知功能。
- 情绪起点：常见的是"被说中"的认同感，以及"我是不是有问题"的自我怀疑。
- 片子要给认同，但不能停留在认同；最终落在行动上。

## 内容结构（已细化为 12 段，详见 `storyboard/storyboard.md`）

| 段落 | 核心信息 | 视觉方向（草案） |
| --- | --- | --- |

| 框架 | INFP 在荣格类型学中的功能顺序：Fi 主导、Ne 辅助、Si 第三、Te 劣势。标明"理论模型" | 四个功能按强弱排成层级，主次用尺度与亮度区分 |
| 发展 | 功能逐步成熟：不熟练多是"还没到"，不是"有问题" | 时间线刻度前进，功能圆依次亮起 |
| 特质 | Fi：以内在价值判断"对不对"；Ne：看见许多可能性 | Fi 为中心光点，Ne 从中长出分叉的线 |
| 原生状态 | 1. 可能性太多，行动太少（Ne 发散、Te 弱）<br>2. 封闭回路：只在内心与回忆中反复评判（社区说法"Fi-Si 回路"）<br>3. 压力下劣势功能爆发：变得挑剔、苛刻、急于掌控（Quenk 的"劣势功能"理论） | 分叉线无法落地；线条闭合成圆圈反复绕行；高压时外圈突然变得尖锐 |
| 中阶成长 | 用 Ne 向外连接，而不是只在脑中模拟；先做小的、可完成的事；学会表达边界 | 圆圈被打开，一条线伸向外部并第一次接触到"世界" |
| Si 的锚点 | 健康的 Si：记得什么对自己真正重要，给发散一个回来的地方 | Si 沉到地面成为桩，Ne 线探出后落回 |
| 反复 | 成长不是直线：会退回，但认得出、回来得更快 | 环合拢又打开三次，每次更快更薄 |
| 高阶成长 | Te 被整合：把价值落成结构、计划与产出；Fi 从评判自己变成指引方向 | 内在光点与外部路径连接，路径上出现一个个完成的节点 |
| 边界与收尾 | 类型是语言，不是诊断；看行为，不贴标签。片尾一句说明 MBTI 的科学争议 | 四个字母退场，留下那条已经走出来的路 |

## 知识边界

本片的每条表述按以下三类标注，记录在 `research/sources.md`：

| 类别 | 例子 | 片中写法 |
| --- | --- | --- |
| 理论 | 荣格心理类型、MBTI 功能顺序、劣势功能 | "在类型学中""这个框架认为" |
| 社区说法 | "回路（loop）"、"中高阶成长"阶段划分 | "常被描述为""社区里常说" |
| 有实证 | MBTI 的信度与效度争议；与大五人格的部分对应 | 片尾边界说明，来源待核实 |

- 不使用"科学证明""INFP 一定"。
- 不把普遍行为写成 INFP 专属（避免巴纳姆效应）。
- 不涉及心理疾病诊断；"压力下苛刻"不等同于任何临床状况。
- 具体文献（作者、年份、书名）在 `research/` 中核实后才能进入画面，未核实前标"待核实"。

## 风格方向（草案）

- **不沿用**其他作品的黑底金色或雨夜剪影。
- **色彩**：雾面纸白底，墨蓝作为主色，一种低饱和苔绿作为"行动/落地"的强调色。强调色只在中高阶成长段落出现，用颜色本身标记转变。
- **造型**：抽象几何。光点、线、圆圈、路径；不画人物，不使用十六型人格常见的卡通形象。
- **母题**：一个内在光点（Fi）贯穿全片。它从"被包裹"到"被困在回路中"再到"连接外部路径"，状态变化就是成长弧线。
- **字体**：中文衬线或宋体做主文案，营造内省感；功能缩写（Fi、Ne 等）用等宽字体作为标签。
- **竖屏构图**：主视觉在画面中上部，字幕在下三分之一以上，避开抖音底部 UI 遮挡区域；顶部同样避让。

## Suno 配乐提示词

纯音乐，结构对应片子的情绪弧线：内省 → 困顿 → 打开 → 舒展。

**Style**
```text
instrumental, ambient piano, soft felt piano, warm analog pads, subtle music box, light field recording texture, minimal, introspective, gradually uplifting, gentle build, no drums in first half, soft brushed percussion later, 72 BPM, cinematic, no vocals
```

**Exclude**
```text
vocals, singing, choir, rap, EDM, heavy drums, distorted guitar
```

[Bridge]

## 技术与交付

- 遵循 `prompt/core/production.md`、`prompt/core/framing.md` 与 `prompt/media/web.md`；单文件 HTML，Canvas 2D + DOM 字幕，无构建。
- 多画幅策略：重新构图。9:16 与 16:9 共享时间轴与状态，只切换布局；用 `?ratio=9x16` / `?ratio=16x9` 切换，默认 9:16。
- 9:16 安全区（暂定）：顶部 12%、底部 20% 避让平台界面；字幕位于 66%–79% 高度（v2 风格帧确认）。发布前按实际界面复核。
- 支持 `renderAt(t)` / `window.ready` / `?capture&t=`。
- 支持本地载入 Suno 音频，以音频时间为主时钟；提供校准模式，用户边听边按键标记段落起点，页面输出新的锚点表。
- 音频由用户生成并持有，入库前确认 Suno 会员条款下的使用权。
- 视频导出（截帧合成）不在本轮范围。
