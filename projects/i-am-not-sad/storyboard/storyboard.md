## 段落 00 · 前奏：靠近那扇门

**时间**：0:00–0:31（31s）
**目的**：建立空间、氛围和「门」母题；主角从远处走来，暗示犹豫
**起始状态**：黑屏，雨声质感的细线开始落下。远处一扇门透出暖光，是画面唯一的光源。地面有湿润反光
**触发**：3s 左右标题「我不难过」以大字短暂浮现后淡去，像呼吸一样
**状态变化链**：
1. 0:00–0:06 黑暗中雨丝逐渐显现，门的暖光从一个小点扩散成矩形轮廓
2. 0:06–0:10 标题出现 → 停留 → 退去。副标题不需要
3. 0:10–0:20 主角剪影从画面左下远处出现，缓步靠近门的方向。脚步在湿地面留下短暂反光
4. 0:20–0:31 主角走到门前停下，门内暖光映在主角身上形成轮廓光。另一个人影在门内隐约可见

**视觉重音**：主角停在门前的瞬间（~0:25），门内光最亮，两人距离最近但隔着门
**结果状态**：两个剪影隔门相对，暖光笼罩
**与下段联系**：门打开，进入面对面的沉默

## 段落 01 · 门口沉默

**时间**：0:31–0:46（15s）
**歌词**：又站在你家的门口 / 我们重复沉默 / 这样子单方面的守候 / 还能多久
**目的**：两人相对无言，暖光开始衰减——关系已经出现裂缝
**起始状态**：门已开，两人面对面站在门框两侧。门内暖光饱满
**触发**：歌词开始，「又站在你家的门口」
**状态变化链**：
1. 0:31–0:37 两个剪影面对面静立，间距约门框宽度。门内暖光缓慢变暗（饱和度和面积都在缩减）
2. 0:37–0:41 「这样子单方面的守候」—— 主角微微前倾，对方没有回应动作。光继续衰减
3. 0:41–0:46 「还能多久」—— 门内光降到最暗，两人之间的空间变冷。地面暖色反光消失

**视觉重音**：「还能多久」时光降到谷底（~0:43），画面几乎只剩轮廓
**结果状态**：两人仍在原位，但包裹他们的光已经很弱
**与下段联系**：对方开口（身体姿态变化），引出第三人

## 段落 02 · 第三个人

**时间**：0:46–1:01（15s）
**歌词**：终于你开口向我诉说 / 她有多温柔 / 虽然你还握着我的手 / 但我已不在你心中
**目的**：关系中出现第三个存在，连接被打破
**起始状态**：两人隔门站立，暗调
**触发**：「终于你开口」—— 对方的剪影有了说话的姿态暗示（头微转，肩动）
**状态变化链**：
1. 0:46–0:50 对方身体微动（开口的暗示），两人之间出现一条细细的连线（光线/丝线），代表尚存的联系
2. 0:50–0:53 「她有多温柔」—— 画面远处（门内深处或上方）出现第三个光点，柔和但明确。连线开始被这个光点吸引弯曲
3. 0:53–0:57 「虽然你还握着我的手」—— 镜头推近到两人之间，能看到两只手还相握。手的连接处有微弱的暖光
4. 0:57–1:01 「但我已不在你心中」—— 连线断裂成碎点漂向第三个光源。手虽然还握着，但手部的光熄灭了

**视觉重音**：连线断裂的瞬间（~0:58），伴随短暂的粒子散落
**结果状态**：两只手形式上相握，但光已转移到第三者方向
**与下段联系**：镜头继续聚焦在手上，进入「理解」段

## 段落 03 · 我真的懂（第一次）

**时间**：1:01–1:23（22s）
**歌词**：我真的懂你不是喜新厌旧 / 是我没有 / 陪在你身边当你寂寞时候 / 别再看着我 / 说着你爱过，别太伤痛
**目的**：主角试图理解和体面退出，但身体语言出卖了不舍。第一次「我真的懂」——嘴上说懂
**起始状态**：两只手相握的特写，暗调
**触发**：「我真的懂」
**状态变化链**：
1. 1:01–1:09 画面保持在手的特写，主角的手指微微收紧（不是松开）。「是我没有」时主角的手轻轻颤动
2. 1:09–1:16 镜头缓缓拉远，看到两个人的上半身。主角面朝对方，身体仍然靠近。「别再看着我」但主角并没有转身
3. 1:16–1:23 「说着你爱过，别太伤痛」—— 对方的剪影开始后退半步，主角伸手的姿态定格。两人之间的空间首次明显拉开

**视觉重音**：「别再看着我」（~1:12）主角的剪影有个微小的抽离动作但立刻收回，暴露了矛盾
**结果状态**：两人之间出现了明确间距，主角仍面朝对方
**与下段联系**：情绪积累到临界点，进入副歌——泪水

## 段落 04 · 我不难过（第一次副歌）

**时间**：1:23–1:55（32s）
**歌词**：我不难过，这不算什么 / 只是为什么眼泪会流 / 我也不懂 / 就让我走，让我开始享受自由 / 回忆很多 / 你的影子也会充满我生活 / 我并不懦弱，你比谁都懂 / 虽然寂寞，这会是我最后的宽容
**目的**：否认与溃堤。嘴上说不难过，泪已经落下。第一次副歌，画面仍有暖色残留
**起始状态**：两人之间有间距，主角面朝对方

### 04a · 眼泪（1:23–1:38）

**触发**：「我不难过」—— 这句话本身
**状态变化链**：
1. 1:23–1:27 画面上推到主角的头部剪影特写。「我不难过，这不算什么」—— 头微微抬起，像在忍
2. 1:27–1:31 「只是为什么眼泪会流」—— 眼部位置出现一滴光点，沿面部轮廓缓慢滑落。这是全片第一滴泪
3. 1:31–1:33 「我也不懂」—— 泪滴落到下方，在地面形成一个小光圈扩散
4. 1:33–1:38 「就让我走」—— 主角的剪影开始转身，从面朝对方变为侧身。画面中仍有残存的暖色光晕

**视觉重音**：第一滴泪落下（~1:28），画面有微小的停顿感

### 04b · 走开与宽容（1:38–1:55）

**状态变化链**：
1. 1:38–1:44 画面切到更开阔的空间——一条有纵深的路。主角剪影开始缓步前行，身后是门和留在那里的对方
2. 1:44–1:48 「你的影子也会充满我生活」—— 对方的虚影跟在主角身侧，半透明
3. 1:48–1:52 「我并不懦弱」—— 主角的步伐稍稍加大，但虚影仍在
4. 1:52–1:55 「这会是我最后的宽容」—— 主角停步，回头看了一眼。门口的暖光还亮着一点点

**视觉重音**：回头一眼（~1:53），画面暂停推进，主角和远处门光形成对角构图
**结果状态**：主角在路上，半转身，门口光微弱
**与下段联系**：回头引发回忆涌来

## 段落 05 · 回忆

**时间**：1:55–2:15（20s）
**歌词**：无歌词（器乐/情绪段）
**目的**：回忆涌现又消散，温柔但抓不住
**起始状态**：主角站在路上，半回身
**触发**：主角回头的动作触发记忆画面
**状态变化链**：
1. 1:55–2:00 主角周围开始浮现半透明的暖色光片——像照片或窗口，每个里面有两人在一起的剪影片段（并肩走、靠在一起、牵手跑）
2. 2:00–2:07 光片逐个亮起又缓缓淡去，像气泡浮上来又破裂。主角伸手去触，手穿过光片
3. 2:07–2:12 光片越来越淡，飘散方向一致（风向暗示）。主角的手停在空中
4. 2:12–2:15 所有光片消散完毕。画面只剩主角独自站在路上，周围比之前更空

**视觉重音**：手穿过光片的瞬间（~2:04），触不到的具象化
**结果状态**：主角独立在空旷的路上，回忆散尽
**与下段联系**：间奏延续空旷感，为第二段蓄力

## 段落 10 · 拥抱与告别

**时间**：3:30–3:45（15s）
**歌词**：（回忆/情绪段过渡）
**目的**：全片唯一一次真正的身体接触——拥抱。短暂的温暖后松开
**起始状态**：主角在路上前行
**触发**：主角停步，对方从身后出现
**状态变化链**：
1. 3:30–3:34 主角停下，对方的剪影从身后接近——这是记忆还是现实？光线暧昧
2. 3:34–3:38 两个剪影相拥，手臂环绕形成封闭轮廓。拥抱处有一个暖光团，是全片后半段唯一的暖色回归
3. 3:38–3:42 暖光团开始从中心向外消散，像最后一口气。两人的轮廓开始松开
4. 3:42–3:45 完全分开，对方的剪影后退、变淡直到消失。暖光团彻底熄灭

**视觉重音**：拥抱合拢的瞬间（~3:36），暖光最亮，是后半段唯一的温度峰值
**结果状态**：主角独立，对方消失，暖光熄灭
**与下段联系**：进入桥段——从「抱紧」到「随风」的转折

## 段落 11 · 抱紧我 → 随风（桥段）

**时间**：3:45–4:10（25s）
**歌词**：抱紧我，再抱紧我 / 这一份感动请你让我留在胸口 / 别再说是你的错 / 爱到了尽头 / 是非对错，就让它随风 / 忘了所有，过得比你快活
**目的**：全片情绪转折点。从「求」（抱紧我）到「放」（随风）。风取代雨成为主导元素
**起始状态**：主角独立，空旷
**触发**：「抱紧我」—— 但这次没有人回应

### 11a · 抱紧（3:45–3:55）

**状态变化链**：
1. 3:45–3:48 「抱紧我」—— 主角双臂环抱自己的姿态，是在抱空气。周围的雨丝开始倾斜
2. 3:48–3:52 「请你让我留在胸口」—— 主角的轮廓内有一个微弱的光点（残存的感情），在胸口位置
3. 3:52–3:55 「别再说是你的错」—— 风开始加强，雨丝变成接近水平的方向

### 11b · 随风（3:55–4:10）

**状态变化链**：
1. 3:55–4:00 「是非对错，就让它随风」—— 画面中所有散落的视觉碎片（之前的连线碎点、回忆光片残骸、泪的光圈）开始被风横向吹走
2. 4:00–4:05 「忘了所有」—— 主角的剪影边缘开始有细小的颗粒被风带离，像在蜕皮
3. 4:05–4:10 「过得比你快活」—— 风势平缓，碎片已远去。画面干净了。主角的剪影重新变得清晰锐利

**视觉重音**：碎片被风吹走的高潮（~4:00），画面最大的横向运动，是全片的动态峰值
**结果状态**：画面被风清扫干净，主角轮廓清晰。一个被清空的起点
**与下段联系**：干净的状态进入最后一轮

## 段落 12 · 我真的懂（第三次）

**起始状态**：主角独立在清扫后的空旷中，面朝前方
**触发**：第三次「我真的懂」

2. 4:17–4:24 「是我没有陪在你身边」—— 画面中对方已完全不存在，没有剪影，没有光点，没有虚影。主角也不再寻找

**视觉重音**：天光出现（~4:26），从地平线渐渐亮起——不是突然的救赎，是慢慢的可能性
**结果状态**：主角面朝有天光的方向，身后的门几乎看不见了
**与下段联系**：进入最后的副歌和终曲

## 段落 13 · 松手（最后的副歌与结尾）

**时间**：4:33–4:52（19s）
**歌词**：我不难过，这不算什么 / 只是为什么眼泪会流 / 我也不懂 / 不要再说或许这是最好的结果 / 现在分手总好过你不爱我一拖再拖 / 松开你的手，离开你左右 / 我向前走 / 这会是我真正的解脱
**目的**：第三次「我不难过」——真正放下了。没有泪，前方有光，主角走出画面
**起始状态**：主角面朝天光方向
**触发**：最后的「我不难过」
**状态变化链**：
1. 4:33–4:37 「我不难过，这不算什么」—— 主角的脸（剪影）朝向天光，没有泪。声音和画面都比前两次平静
2. 4:37–4:41 「只是为什么眼泪会流，我也不懂」—— 这次没有泪落下。歌词是回忆在说话，画面已经走过了那个阶段
3. 4:41–4:46 「松开你的手，离开你左右」—— 主角的手从身侧自然垂下→微微张开→松开。一个无形之手的松开动作。最后的母题回归
4. 4:46–4:49 「我向前走」—— 主角迈步走向天光方向，步伐平稳（不急不慢，不回头）。身后留下一串脚印在湿地面
5. 4:49–4:52 「这会是我真正的解脱」—— 主角走入天光中，轮廓逐渐被光吞没但不是消失——是融入。脚印留在画面中

**视觉重音**：主角走入光中（~4:50），是全片最亮的瞬间，但不是暖色——是冷白的、清醒的光
**结果状态**：主角融入天光，画面只剩地面上的脚印和渐渐平息的微风。光慢慢降回正常明度
**尾声**：4:52 后画面停留 3–5 秒，脚印缓缓被微风中的细小颗粒覆盖，但不完全消失。黑屏

## 技术备注

- 全部 Canvas 2D，不使用 Three.js
- 人物为剪影，通过轮廓、姿态、手的位置传达，不画五官
- 雨丝：倾斜的短线段阵列，密度和角度随风变化
- 光效：径向渐变 + globalAlpha 叠加
- 回忆光片：圆角矩形 + 内部简笔剪影 + 浮动轨迹
- 脚印：半透明椭圆序列，随时间缓慢淡化
- 风的碎片：小圆点/短线段，统一方向的加速运动
- 泪：贝塞尔曲线路径上的光点，第一次单个，第二次连续，第三次无
