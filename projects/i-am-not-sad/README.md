# 《我不难过》歌曲动画

孙燕姿《我不难过》的自动播放歌曲动画，4 分 52 秒，覆盖完整歌曲结构。

## 主题

一段关系中，一个人从被动等待到主动松手的完整情绪弧线：不舍 → 理解 → 伪装坚强 → 真正放下。

## 视觉母题

- **门** — 关系的边界，暖光从饱满到熄灭
- **手** — 连接与断开，从紧握到松开
- **光与暗** — 情绪温度，暖光逐渐让位于冷色天光
- **雨与风** — 压抑到转折到释放
- **距离** — 两人之间的空间变化

歌曲副歌重复三次，每次画面递进而非复制。详见 [分镜](storyboard/storyboard.md) 中的母题变化总览。
