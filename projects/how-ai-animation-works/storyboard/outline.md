# 样片结构

核心问题：用 AI 编写 Web 知识动画，需要哪些环节？

观看目标：分清人的内容决策、AI 编写代码、浏览器绘制和最终视频渲染。

| 时间 | 镜头 | 解释动作 |
| --- | --- | --- |
| 0–6s | 一段动画，如何诞生 | 骰子旋转下落、衰减回弹，标注物体与动作 |
| 6–12s | 先有问题 | 沿用同一骰子并缩小，展开六面，引出解释目标 |
| 12–18s | 分镜 | 一次 → 许多次 → 整体，三个画框依次建立 |
| 18–24s | AI 写代码 | 保留骰子，代码逐行出现，连接分镜与实现 |
| 24–30s | 浏览器绘制 | 并列展示 Three.js、Canvas 与文字排版 |
| 30–36s | 时间轴 | 播放、回退、停在同一时间，验证画面可复现 |
| 36–42s | 导出 | 帧序列逐个出现，声音轨道作为合成流程示意 |
| 42–48s | 收束 | 回看骰子与图表，总结制作链路 |

首版采用硬切与镜头内错峰，保持字体、物体和颜色一致。未声称三种绘制技术是所有动画的必要条件，描述的是本片采用的 Web 路线。
