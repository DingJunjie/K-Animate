# 一段动画，如何诞生

32 秒字幕样片，解释 AI 编写 Web 知识动画的流程：问题 → 分镜 → 代码 → 浏览器绘制 → 时间轴 → 视频。

## 预览

在仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 http://localhost:8000/projects/how-ai-animation-works/src/ ，点击播放或按空格。左右方向键逐秒定位，底部进度条可拖动；鼠标移入显示控件。

截帧示例：`src/?capture&t=25`。先等待 `window.ready`，可调用 `window.renderAt(25)`。全部画面由指定时间确定，无随机累积状态。

## 实现与边界

- HTML/CSS：标题、逐字字幕、控件。
- Canvas 2D：图解、图表、装饰微尘。
- Three.js：实体骰子、光照与旋转；本地 vendored 0.160.0，MIT 许可，来源 cdnjs。
- Google Fonts：Noto Serif SC 与 IBM Plex Mono，提供本地字体回退，首次加载需要网络。
- 本片为字幕版，无旁白、音乐或已导出的 MP4；声音合入属于片中解释的制作步骤。
- 骰子使用可控姿态与衰减回弹，并非物理模拟；统计柱形仅为流程图解，不是试验数据。

首版用于评估解释逻辑、视觉衔接与审美，尚未提取为共享引擎。

## 节奏修订

移除字幕逐字扫亮，字幕按语义整句展示；标题分段出现，重点字使用短促弹性缩放。缩短原版等待时间，增加组内焦点与帧序列扫描。仍未添加音轨，当前节奏依据文字和视觉动作设计，并非音乐卡点。
