## 总体

- 结构：角度一「怕被看见」（0–40s）→ 角度二「想被看见」（40–60s）→ 机制：聚光 vs 分散（60–75.4s）→ 为什么 + 收尾（75.4–116s）。
- 每个角度都是「以为 → 真实」：想象用聚光、暖色、重暗角；真实用普通教室灯、去饱和、各做各的。
- 片名「聚光灯效应」**直到 109s 才出现**，从灯光中收拢而成；此前角标只写研究出处，不写片名。
- 一拍 = 一次状态变化（约 3–5s），**不等于一次切镜**。同一场景的连续几拍做成流畅的一镜到底，只在换地点或「想象 → 真实」时切。
- 知识边界：只用一个数字「大约四分之一」（23%，用户决定使用，未经原文核实）。「很快就忘了」「想被看见也没人注意」是生活观察，不写成研究结论。机制「以自身感受为起点、调整不足」待核实。人数、光点数为示意。

## 为什么 + 收尾（75.4–116s）

| 时间 | 场景 | 状态变化 |
| --- | --- | --- |
| 75.4–80 | S5 | 停留消化；「每个人，都在自己的灯下。」 |
| 80–84 | S6 抽象 | 你的光很亮，于是以为别人看你也这么亮 |
| 84–87 | S6 | 箭头从你出发走向别人，走到一半停住 |
| 87–91 | S6 | 「我们会替别人想一想，只是走得不够远。」（机制待核实） |
| 91–95 | S7 合照 | 每个人第一眼都在找自己 |

| 102–106 | S2 → S1 | 聚光灯慢慢变成普通的灯，红线变成普通的头发 |

| 109–112 | S1 → 片名 | 你抬头看灯：普通灯泡收拢成一束聚光，光束里显出片名「聚光灯效应」，下方小字 Spotlight Effect · Gilovich, Medvec & Savitsky (2000) |
