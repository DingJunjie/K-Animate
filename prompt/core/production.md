# 工程约定

本文件规定所有模式、所有载体共用的工程与交付边界。审美方法见 [visual-design.md](visual-design.md)，画幅见 [framing.md](framing.md)；具体实现方式见 `../media/<载体>.md`；风格、主题、时长与交付要求由各片任务书决定。

## 目录

- 项目的任务书、依据、分镜、资产和源码放在对应作品目录：`projects/<name>/{prompt,research,storyboard,assets,src,output}`。`output/` 不入库。
- 通用代码先在作品内实现，经多个作品实际使用后再提取到 `shared/`。
- 文件夹使用稳定的英文标识，中文名称写在项目 README 中。

## 载体

任务书声明载体，并加载对应文件：

| 载体 | 文件 | 说明 |
| --- | --- | --- |
| `web` | `../media/web.md` | 浏览器代码动画：时间轴、截帧接口、校准模式 |
| `ai-video` | `../media/ai-video.md` | AI 视频生成：镜头表与逐镜提示词（待建立） |

根据所需效果选择载体与技术，避免由已有组件或工具反向决定题材和造型。

## 资产与许可

- 资产记录来源、许可和用途，包括 AI 生成的图像、视频与音乐所用的工具和条款。
- 交付注明外部依赖。

## 声音

- 未获授权的音频不入库。
- 未实际对齐音频前，不声称已实现音乐卡点；时间标为「待校准」。

## 交付形式

预览页面、单文件 HTML 和视频是不同交付形式，按本次需求选择，不默认为同一件事。

## 检查

- 根据本轮重点检查实际画面与播放，记录观察到的问题。
- 每个声明画幅都实际检查，不只看主画幅。
- 说明声音、导出或其他尚未完成的部分，不把流程示意当成已经实现的功能。
