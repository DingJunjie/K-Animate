# 视觉设计

先提出适合本片的视觉方向，并说明它与主题的联系。根据所需效果选择技术，避免由已有组件反向决定题材和造型。

## 把形容词转成设计选择

把「高级」「电影感」「温柔」等形容词转成可执行的设计选择：

- 构图：主体比例、视觉重心、负空间、前中后景、裁切与镜头距离。
- 色彩：主次色、明度关系、强调色的用途，以及相邻段落的变化。
- 形态与材质：几何或有机、平面或立体、边缘与表面细节，维持一致的造型语言。
- 光影：光源方向、软硬、接触关系、体积与空间层次；平面风格可以不模拟真实光照。
- 字体：选择理由、字号对比、字重、行距与留白；文字可主导，也可退为标签。
- 细节：只有在需要时采用纹理、粒子、辉光、景深等效果，控制它们对主体的影响。

## 统一语言，不统一布局

统一的是本片的设计语言，不要求所有段落复用同一种布局。避免把连续画面做成相同标题、相同卡片和相同入场方式的轮播。

为相邻段落设计疏密、尺度与明度的反差。主体可以铺满画面，标题可以短暂独占画面，局部细节也可以放大；不让所有段落保持相同信息量与视觉强度。卡片、正文和固定标题只在有组织信息的必要时使用。

## 不预设风格

不预设黑底、金色、衬线、粒子、仪表、三栏卡片或特定道具。风格选择属于本片任务书，可另存为可选风格参考，不作为所有作品的默认要求。

具体道具、故事、符号和隐喻属于各片，跨片使用前重新判断主题适配。主题不需要实体隐喻时，不强加道具。

## 审美试片

审美试片应包含能代表本片的构图、材质和实际运动，观察入场、变化与停留，而不只展示静帧。
