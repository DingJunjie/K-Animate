# 动作、衔接与节奏

## 视觉段落的状态变化链

一个对象或关系通过连续状态变化完成一段理解或情绪推进：起始画面 → 触发 → 连续变化 → 视觉重音 → 结果停留 → 下段联系。

变化可以是生长、累积、删减、分类、变形、靠近、分离、参照切换、预测或结果反馈，按主题选择，不要求全部使用。

段落是一个完整的观看任务，内部可以有多个节拍。片长、段落数和停留时间由内容密度、阅读、动作与情绪决定，不套固定数量或等长切片。

每个节拍标明「观众新看到了什么，因此理解或感受发生什么变化」。淡入一张卡片不自动等于推进；若动作只装饰文字，需要重新考虑能否把关系、过程或情绪直接画出来。

## 动作设计

设计动作时说明初始状态、触发、路径、速度变化、结束状态与停留。根据对象和表达选择惯性、弹性、匀速、突变或稳定；匀速适用于需要表达恒定速度的过程，不统一禁止。

注意重量、接触、遮挡、支撑、空间方向与比例变化。写实、示意与夸张可以选择，但应维持各自的视觉规则。

## 衔接

衔接可来自形状、位置、运动方向、颜色、尺度或概念关系。需要比较时保留参照；需要重置注意力时可以切开。连续性服务观看，不强求一镜到底，也不要求固定主角贯穿全片。

新信息推进时，不必清空整幅画面；保留比较所需的视觉参照，让观众能看见前后区别。

## 节奏

节奏来自轻重、快慢与变化，不等于所有元素不停运动。为不同阶段设计不同节拍：搭建、加速累积、揭示、反转、消化。让局部事件决定节拍，用不同强度安排注意力，避免全片都处于高潮。

整体提速不能只靠统一缩短段落。主体动作完成后，判断是否应推进下一信息，而非为填满时长持续静置；需要理解或情绪消化的停留仍应保留。

## 文字动效

文字本身也可以承担节奏：按语义分组出现，用尺度、位置、字重或短促弹性强调转折与关键词，平静段落则保持克制。不要机械地为所有句子套同一种入场效果。

默认字幕整句或按语义短句呈现，避免逐字扫亮替观众规定阅读速度。文字弹性缩放是可选重音，不能代替主体的状态变化。

## 声音

有音乐时，把重要揭示、动作接触和镜头转折与音乐乐句或重音协调。音乐是可选项；未提供音轨时按视觉节拍设计，不声称已经实现音乐卡点，也不把音波示意当成实际配乐。

## 复查问题

- 长段落内部是否持续提供必要的新信息或情绪变化，短段落是否留下足够消化时间？
- 是否把统一加速、全篇弹字或装饰循环误当成节奏？
- 视线是否有主次，段落之间是否有呼吸和变化？
