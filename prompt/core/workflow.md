# 制作流程

本流程是所有模式共用的创作与检查骨架，不要求每片套用相同故事顺序、风格或固定镜头数。各模式在 `../modes/` 中补充本模式的前置分析与检查项。

## 1. 确定观看结果

写清主题、观众已有认知或情绪起点、希望发生的理解或情绪变化，以及本轮重点。确认载体是自动短片还是用户另行指定的产品。按模式完成前置分析（如知识片的事实核查、歌曲片的歌词与音频结构），并确定载体与画幅（见 [framing.md](framing.md)）。

## 2. 设计视觉段落

以「视觉段落」组织创作：一个对象或关系通过连续状态变化完成一段理解或情绪推进。先设计状态变化链，再确定镜头和时长。段落卡格式见 [segment-card.md](segment-card.md)。

先判断变化能否表达观点或情绪，再决定是否需要主文案。允许同一主视觉持续多个节拍，不用为每句话建立新页面。

## 3. 设计审美与节奏

确定本片的造型、材质、色彩、字体与空间语言，方法见 [visual-design.md](visual-design.md)。选择相邻段落的密度、尺度和动静对比，不逐镜头重复同一容器。用不同强度安排注意力，避免全片都处于高潮。

参考中的对象和故事留在参考案例中；只抽取可迁移的方法。

## 4. 排事件与文字

按具体动作、阅读与理解需求分配时间，方法见 [motion-rhythm.md](motion-rhythm.md) 与 [audience.md](audience.md)。场景表记录视觉段落与内部事件时间，而不只是每页的标题与入场效果。字幕按语义短句显示，标题与关键词动效只在需要时强调。

有音轨时再协调乐句、重音与动作；没有音轨则按视觉节拍设计并如实标注。

## 5. 先做代表性动态段落

优先实现最能验证本片审美与表达方式的一段，包含状态变化和衔接，不只验证静帧。时长按试验目标决定，不统一规定秒数。用户已授权完整制作时，验证后继续完成，不额外停下来索要批准。

## 6. 完成与观看检查

按载体完成执行层（网页的事件时间表、AI 视频的镜头表，见 `../media/`），作品默认连续播放。以普通观众速度看完整段落，检查注意力、阅读、空等、重复布局和前后参照；抽帧辅助检查材质与排版，不能代替动态检查。

修改针对具体问题：无推进则重排事件；画面同质则调整构图、尺度与密度；理解困难则增加参照或调整信息顺序；情绪平淡则调整重音与停留。不能只把全片统一加速。

复盘顺序：先看无字幕版本，能否感到关系或情绪变化；再看无声音版本，动作是否有节奏；最后看完整版本，文字与声音是被画面重复，还是被画面扩展。
