# 提示词体系

本目录是所有动画作品的创作方法。分三层，上层对所有下层成立，下层只补充与收窄。

第二层有两个相互独立的维度：**模式**（讲什么、如何组织表达）与**载体**（用什么做出来）。**画幅**是第三个独立维度，方法写在 `core/framing.md`，具体选择写在任务书。

## 分层

```text
prompt/
  core/                 第一层：所有作品模式都成立的通用方法
    director.md         入口：角色、作品形式、输入、交付边界、层级规则
    workflow.md         通用制作流程（6 步）与复盘顺序
    visual-design.md    构图、色彩、形态、光影、字体；不预设风格
    motion-rhythm.md    状态变化链、动作、衔接、节奏、文字动效、声音协调
    audience.md         注意力主次、文字分工、停留与表达边界
    segment-card.md     段落卡格式、快速评分与密度参考（与载体无关）
    framing.md          画幅、安全区、多画幅策略
    production.md       所有载体通用：目录、载体选择、资产许可、声音授权、检查
  modes/                第二层 · 内容维度
    knowledge.md        知识片：理解主题、拆解步骤、类比边界、事实依据、选题类别
    song.md             歌曲片：歌词与音频分析、角色母题、重复递进（song-story / lyric-visual）
  media/                第二层 · 载体维度
    web.md              网页代码动画：时间轴、锚点、截帧接口、校准模式、事件时间表
    ai-video.md         AI 视频：镜头表、提示词结构、一致性、后期分工
    ai-video/           具体工具（用到时查官方文档后再建）
  references/           案例与历史存档，不作为规则
  TODO.md               全局制作待办

projects/<name>/prompt/brief.md   第三层：单片任务书
```

## 加载顺序

1. 读 `core/director.md`，再按需读 `core/` 其余文件。
2. 按任务书声明的模式读 `modes/<模式>.md`，按声明的载体读 `media/<载体>.md`。
3. 读项目 `prompt/brief.md`。

## 归属判断

一句规则如果对任何一种模式不成立，就不属于 `core/`。

- 对所有模式、所有载体成立 → `core/`
- 只对某一模式成立 → `modes/<模式>.md`
- 只对某一载体成立 → `media/<载体>.md`
- 只对某一部作品成立 → 项目 `brief.md`
- 对一个系列成立 → 系列层文件（待第一部完成后提取）

下层要推翻上层时，在 brief 中写明「例外：……」及理由；不在下层重复上层内容。

## 作品模式

| 模式 | 优先 | 文件 |
| --- | --- | --- |
| `knowledge` | 事实与理解，画面证明概念 | `modes/knowledge.md` |
| `song-story` | 情绪、歌词与角色弧线 | `modes/song.md` |
| `lyric-visual` | 歌词与视觉节拍，允许抽象 | `modes/song.md` |
| `concept-film` | 主题与视觉隐喻 | 暂未建立，有项目需要时再写 |

模式先用单文件；内容增多后再升级为文件夹。

## 载体

| 载体 | 执行层分镜 | 文件 |
| --- | --- | --- |
| `web` | 事件时间表 | `media/web.md` |
| `ai-video` | 镜头表 + 逐镜提示词 | `media/ai-video.md` |

同一份段落卡可以同时供多个载体使用；执行层分镜按载体分别写。

## 任务书模板

```markdown
# 《作品名》任务书

- 模式：knowledge / song-story / lyric-visual
- 载体：web / ai-video（可多个）
- 画幅：主画幅 + 其他画幅；多画幅策略（重新构图 / 主画幅加裁切）；安全区数值
- 系列：（如属于系列，写系列名与序号）
- 观众（立项第 0 步）：发布平台；谁会看、谁不会看；已有认知、情绪起点与审美偏好；开头几秒用什么抓住他们
- 主题与观看结果：观众要理解或感受到什么；希望观众在哪一刻觉得「原来如此」
- 声音：音乐来源与授权；节拍、BPM、风格，以及它为什么适合这群观众（歌曲片以歌曲本身为准）
- 时长：按平台与观众决定，写明理由
- 材料：参考、歌词时间表、音频版本、研究来源
- 风格方向：视觉类型（日常物件 / 隐喻 / 图解，可组合，写明主次）；本片的色彩、造型、空间、字体选择及理由
- 技术与交付：依赖、交付形式、未实现部分
- 本轮目标与评审维度：
- 例外：（推翻上层规则时写明理由）
```
