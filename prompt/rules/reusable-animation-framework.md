# 可复用动画导演框架

## 作品模式

- `knowledge`：事实与理解优先，画面证明概念。
- `song-story`：情绪、歌词与角色弧线优先，画面形成可记住的故事。
- `lyric-visual`：歌词与视觉节拍优先，允许抽象联想，不强行补完整剧情。
- `concept-film`：主题与视觉隐喻优先，适合品牌、散文和金句。

## 快速量化（用于排方案，不是硬规则）

给每个视觉段落打 1–5 分：

| 维度 | 1 | 5 |
| --- | --- | --- |
| 主题相关度 | 可替换到别的主题 | 拿掉主题就不成立 |
| 动作信息量 | 只有入场 | 状态变化改变理解或情绪 |
| 视觉重音 | 画面强度平均 | 有明确峰值和释放 |
| 叙事推进 | 重复上一状态 | 关系、目标或情绪发生变化 |
| 可读性 | 文字与动作冲突 | 一眼知道先看什么 |
| 可复用性 | 只适合一个镜头 | 可参数化为组件或方法 |

每 10 秒至少安排 2–4 个可辨识的状态变化；一段连续变化最长约 8–15 秒，除非它本身是核心积累过程。每 10 秒至少有一次视觉重音或构图变化；重音后留约 0.5–2 秒消化。连续静止只在歌词、结论或情绪停顿需要时保留。

## 段落卡

每段记录：`目的 / 起始状态 / 触发 / 变化链 / 重音 / 结果状态 / 时长 / 评分 / 下一段关系`。

## 复盘

先看无字幕版本：能否感到关系或情绪变化？再看无声音版本：动作是否有节奏？最后看完整版本：歌词是否被画面重复，还是被画面扩展？
