# 项目制作约定

本文件规定工程与内容边界。审美方法见母提示词；具体风格、主题、时长与交付要求由各片任务书决定。

自动短片的创作流程见 [animation-workflow.md](animation-workflow.md)。默认由时间轴完整推进，交互控件用于播放与回看，不以滚动和点击承担必需的叙事步骤。

## 内容与主题

- 具体道具、故事、符号和类比属于各片，跨片使用前重新判断主题适配。
- 事实、引文、历史、数据在项目 research 中记录依据；未核实内容显式标记。
- 模拟与示意不得冒充实测，视觉表达应保留必要前提和适用边界。
- 明确本轮评审重点，避免把审美修改扩展成未经要求的全片重写。

## 工程

- 项目源码、资产、分镜和任务书放在对应作品目录。通用代码经实际使用后再提取。
- 默认以 1920×1080 预览，可由项目任务书调整画幅与尺寸。
- 统一时间轴，随机过程使用固定种子；同一时间可重复渲染相同状态。
- 暴露 window.renderAt(t)；window.ready 为资源与初始场景就绪后兑现的 Promise。
- URL 参数 ?capture&t=秒数 隐藏控件、停止播放、定位到指定时间。
- 交付注明外部依赖；资产记录来源、许可和用途。使用本地依赖还是 CDN，由交付环境决定。
- 预览页面、单文件 HTML 和视频是不同交付形式，按本次需求选择，不默认为同一件事。

## 检查

- 根据本轮重点检查实际画面与播放，记录观察到的问题。
- 检查任意跳转、重播、截帧是否一致，资源就绪后再截帧。
- 说明声音、导出或其他尚未完成的部分，不把流程示意当成已经实现的功能。
