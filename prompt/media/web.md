# 载体：网页代码动画（web）

在 `core/` 之上补充用浏览器代码实现作品时的工程约定。通用的目录、资产与交付规则见 [../core/production.md](../core/production.md)。

## 技术选择

- 根据所需效果选技术，避免由已有组件反向决定题材和造型。
- 默认无构建：原生 ES Module、DOM、Canvas 2D；需要真实 3D 时局部使用 Three.js。
- 使用本地依赖还是 CDN，由交付环境决定；交付注明外部依赖。
- 文字优先用 DOM 排版；大量粒子、图形用 Canvas。

## 时间轴与可复现

- 画布尺寸按任务书声明的画幅设置，见 [../core/framing.md](../core/framing.md)。多画幅时共享同一时间轴与状态，只切换布局。
- 统一时间轴；每一帧是时间 t 的确定结果，不依赖累积状态。随机过程使用固定种子，同一时间可重复渲染相同状态。
- 段落以锚点表（起点、时长）组织，段内动画按进度 p（0–1）计算；改锚点时画面整体伸缩，不需重写动画。
- 暴露 `window.renderAt(t)`；`window.ready` 为资源与初始场景就绪后兑现的 Promise。
- URL 参数 `?capture&t=秒数` 隐藏控件、停止播放、定位到指定时间。多画幅时用 `&ratio=9x16` 等参数切换。
- 默认连续播放，提供播放、暂停、进度与回看；交互控件不承担必需的叙事步骤。

## 声音

- 有音轨时，以音频时间为主时钟；无音轨时以页面时钟播放。
- 支持本地载入音频文件同步播放，音频不离开用户电脑。
- 音乐由用户生成或持有、无法提前交给 AI 时，提供校准模式：用户边听边按键标记段落起点，页面输出新的锚点表。

## 执行层分镜

段落卡之外，网页载体需要事件时间表：各元素在何时、以何种曲线发生什么变化，标注所属段落与画幅差异。

## 检查

- 任意跳转、重播、截帧结果一致；资源就绪后再截帧。
- 每个声明画幅都实际播放检查一遍，不只看主画幅。
