# 载体：AI 视频生成（ai-video）

在 `core/` 之上补充用 AI 视频模型生成作品时的通用方法。具体工具（单镜时长上限、分辨率、参数、提示词习惯）更新很快，用到时先查当前官方文档，再在 `ai-video/<工具>.md` 中记录，注明查阅日期。

## 与网页载体的区别

- 画面不是时间 t 的确定结果：同一提示词每次生成不同，需要多次生成后挑选。
- 单个镜头时长有限，长段落要拆成多个镜头再拼接。
- 精确的数量、文字、图表和指定位置的运动难以控制；需要精确表达时，考虑与代码动画或后期合成结合。
- 重新生成成本高，多画幅优先用「主画幅加裁切」，见 [../core/framing.md](../core/framing.md)。

## 从段落卡到镜头表

段落卡（[../core/segment-card.md](../core/segment-card.md)）与载体无关。AI 视频的执行层是镜头表，把每个段落拆成若干镜头：

| 字段 | 说明 |
| --- | --- |
| 镜头编号 | 所属段落 + 序号，如 06-2 |
| 时长 | 不超过所用工具的单镜上限 |
| 画面目的 | 本镜在段落变化链中承担哪一步 |
| 主体与状态 | 起始状态 → 结束状态 |
| 运镜 | 推、拉、摇、移、跟、固定；速度 |
| 参考 | 风格参考图、角色参考、首帧 / 尾帧 |
| 提示词 | 见下方结构 |
| 负面提示 | 需要避免的内容 |
| 衔接 | 与前后镜头如何接：尾帧作下一镜首帧、动作匹配、硬切 |
| 后期 | 字幕、合成、调色、变速等不交给模型的部分 |

## 提示词结构

按固定顺序写，便于逐镜对比和替换：

1. 主体：是谁 / 是什么，外观关键特征。
2. 动作：发生什么变化，从什么状态到什么状态。
3. 场景与环境：空间、时间、天气。
4. 镜头：景别、角度、运镜。
5. 光线与色彩：光源方向、色调、强调色。
6. 风格与材质：画风、质感、参考。
7. 节奏：速度、情绪强度。

一镜只写一个主要动作。动作写成可见的状态变化，不写「表现孤独」这类抽象结论。

## 一致性

- 建立本片的「风格锁」：固定的风格描述段落、色彩词、参考图，每镜复用，不逐镜改写。
- 角色、物件的外观描述写成固定文本，配参考图；同一角色不在不同镜头换描述。
- 需要连续动作时，用上一镜的尾帧作为下一镜的首帧。
- 记录每个选用镜头的提示词、参考、种子（如工具提供）与版本，存入项目 `storyboard/`。

## 文字与字幕

- 字幕、标签、数字在后期添加，不依赖模型在画面中生成文字。
- 镜头构图为字幕区预留空间。

## 声音

- 配乐与音效在剪辑阶段合成；以音乐时间轴安排镜头长度，镜头可在剪辑时变速或裁切。

## 检查

- 逐镜检查是否完成了变化链中对应的那一步，而不只是画面好看。
- 拼接后整片观看：角色、色彩、光线是否跳变，衔接是否成立。
- 模型生成的画面如有违背事实或产生错误印象（知识片尤其注意），重新生成或改用其他载体实现。
