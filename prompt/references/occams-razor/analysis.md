## 关键发现：不是每几秒换一页，而是每几秒推进一次观察

整体约有十余组主视觉系统，许多持续十几秒。内部通过局部动作提供新信息：线条生长、轨迹叠加、计数增加、对象换位、标签出现、数值下降。主视觉不用频繁换掉，观众仍在不断获得新信息。

68–83 秒尤其清楚：

1. 保留消息与一条短解释。
2. 另一条路径向右生长，解释逐项出现。
3. 给路径添加假设数量。
4. 加入每一步的示意可信度。
5. 大数字从 100% 依次经过 80%、64%、约 51%、约 41%，最终约 33%。
6. 完成后仍保留比较关系，字幕给出结论。

这段约十几秒都不是“等观众读同一张图”，而是在同一空间逐步搭建比较。最终阶段也有停留，因此不能把“不停运动”当成规则。

## 审美如何成立

### 主体拥有画面

轨道、分支和曲线直接占据大面积空间。没有反复出现的圆角卡片容器，也没有每镜头都驻留的左上大标题。标题可以独占画面，模型可以铺满画面，公式或引文则可以居中留白。

### 画面的密度有明显反差

分支密集 → 少量大字 → 小光点与空旷星空 → 密集轨道 → 一条椭圆。复杂与简洁的对比既是主题，也是构图节奏。若所有镜头都同样精致、同样整齐，反而没有重音。

### 用少量视觉材料形成系列

细线、光点、衬线字、少量冷暖强调贯穿本片。其作用是维持识别，而非让每个镜头布局相同。紫蓝背景与金白线条是本片的风格选择，不应变成跨片默认。

### 层级来自明度与尺度

活动光点比轨迹更亮；主路径比背景更强；关键数字与标题明显更大。弱化背景信息，观众不必同时读完所有标注。辉光集中在关键位置，而非所有元素都发亮。

## 文字与节奏

- 底部字幕以语义短句呈现；可见关键词的颜色强调。不是持续的逐字扫亮。
- 正文的任务随镜头改变：标题、标签、引文、计数、结论。没有每镜头都附加一句大主文案。
- 动态文字不只有弹跳。本片更明显的手段是分阶段揭示、大小反差、文字和运动对象绑定，以及数字计算。
- 大标题提供停顿与冲击；模型生长提供推进；结论留存提供理解时间。三者交替形成视觉节奏。
- 不能从无音轨文件推断上述变化是否与鼓点或音乐乐句同步。

## 衔接方式

1. 同一对象持续变：同一图形增加轨迹与复杂度。
2. 视觉对比：繁变简、多变少，释放注意力。
3. 形态转换：线条组织成不同形状，连接抽象观点。
4. 情境回收：消息图先提出问题，后用于应用概念，结尾再次返回。
5. 独立切换：无需关联的章节可以切开，统一画面语言足以保持整体感。

不是每个镜头之间都需要 morph，也不是每片都需要唯一物体贯穿。

## 与我们先前版本的差距

| 先前问题 | 参考体现的方法 | 下次实现方向 |
| --- | --- | --- |
| 几乎固定的大标题与三栏卡片 | 主体、标题、模型轮流占据画面 | 每段按内容设计构图和尺度 |
| 做完入场后等待 | 模型内部持续发生有意义的变化 | 先设计状态变化链，再排总时长 |
| 把时长整体缩短来提速 | 局部快慢不同，有搭建也有停留 | 按事件排节拍，不统一每镜头四秒 |
| 弹性标题成为主要动效 | 生长、累积、删减、计算、预测 | 文字动效只是一种手段 |
| 内容是介绍组件 | 图形演示论证本身 | 用画面体现概念区别与结果反馈 |
| 交互网页靠点击推进 | 线性时间驱动，观众被引导观看 | 默认自动时间线，控件仅辅助回看 |

## 方法边界

参考中的聊天概率是解释用的假设示意，不能直接当作真实心理概率；连乘需要相应概率前提。科学史、引文归属与天文表述尚未独立核实。本分析评价表现手法，不等于认可或核实片中所有科学结论。

无法仅凭视频判断作者采用 Canvas、SVG、Three.js、剪辑软件还是混合流程。二维线条与运动可以用 SVG/Canvas 表达，数量多的轨迹可用 Canvas，文字用 DOM；这是实现建议，不是源码识别。

## 应保留的方法

创作单位改为“视觉段落”：一个主题对象或关系，在若干状态变化中完成一个理解任务。

每段设计时记录：起始画面 → 触发 → 连续变化 → 视觉重音 → 结果停留 → 下段联系。由主题决定具体形态，不套用本片的聊天、行星、分支、大象或色彩。

对于 Agent / Skill：值得先验证的不是三张定义卡，而是“一项任务进入 → 执行者遇到选择 → 方法被读取 → 工具产生结果 → 结果不满足 → 执行者调整”的自动演示。它是候选方向，不是本轮已经制作的作品。
